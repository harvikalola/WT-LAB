CSS Multi-Column Layout

CSS multi-column layout is used to divide content into multiple columns. It is useful for newspapers, magazines and other layouts where text needs to flow from one column to another.

The column-count property specifies the number of columns. The column-gap property controls the space between columns. The column-rule properties create a line between the columns.

The column-width property specifies the ideal width of each column. The browser automatically decides how many columns can fit based on the available space.
